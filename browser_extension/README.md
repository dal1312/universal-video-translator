# UVT Browser Link

This optional Manifest V3 extension sends the active HTTP/HTTPS page to the local Universal Video Translator application through the `uvt://` protocol.

It requests only the `activeTab` permission. It has no content scripts, host permissions, analytics, remote server, or access to browser history and cookies.

## Install in Chrome or Edge

1. In Universal Video Translator, select **Collega browser** to register `uvt://` and open this directory.
2. Open `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose this directory.
5. Pin **Send to Universal Video Translator** to the toolbar.

Open a video page and select the extension button. Windows opens UVT, which downloads, translates, and plays the video automatically with Italian audio only.
